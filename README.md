# The Little Dairy website

Website for The Little Dairy Ltd, a certified organic, 100% pasture-fed cow-with-calf dairy at Whittington, near Oswestry, Shropshire.

Plain HTML and CSS, published with GitHub Pages.

- `index.html` – home
- `field-to-folk.html` – experiences: cow cuddling, farm walks, talks
- `blog.html` – blog list; each post is its own page (e.g. `back-on-the-land.html`)
- `style.css` – shared styles
